# 🎮 Sudoku

A clean, fast Sudoku game built with .NET MAUI. No ads. No accounts. No tracking.

**[📦 Download for Windows](https://github.com/jtmunn/SudokuGame/releases/latest)**

---

## Features

- **Five difficulty levels** — Easy through Evil, rated by the solving techniques required
- **Light & dark themes**
- **Auto-save** — picks up where you left off, timer pauses when you tab away
- **Number pad counters** — remaining count per digit
- **Keyboard support** on Windows
- **Optional hints & error checking**

---

## Install

1. Download the `.zip` from the [latest release](https://github.com/jtmunn/SudokuGame/releases/latest)
2. Extract anywhere → run `Sudoku.Maui.exe`

> Windows may show a SmartScreen warning for unsigned apps. Click "More info" → "Run anyway".

Building from source? See [DEVELOPERS.md](docs/DEVELOPERS.md). Something broken? Check [TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).

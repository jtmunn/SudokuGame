# 🎮 Sudoku

> A cross-platform puzzle game built with .NET MAUI — because I love Sudoku, and I love building things.

No ads. No accounts. No tracking. Just a clean, fast Sudoku game that respects your time and your device.

**[📦 Download for Windows](https://github.com/jtmunn/SudokuGame/releases/latest)** · Android/iOS/macOS coming soon

---

## What's inside

- **Five difficulty levels** — Easy through Evil, rated by solving technique (not just clue count)
- **Light & dark themes** — saved between sessions, obviously
- **Auto-save & smart timer** — pauses when you tab away, picks up where you left off
- **Number pad counters** — see how many of each digit are left
- **Keyboard support** on Windows — number keys, Backspace, the works
- **Optional hints** — or turn them off if you're brave

Difficulty is based on the logic required to solve — naked singles, X-wings, swordfish — so "Hard" actually means hard.

---

## Get it running

**Portable (no install needed):**
1. Download the `.zip` from the [latest release](https://github.com/jtmunn/SudokuGame/releases/latest)
2. Extract anywhere → run `Sudoku.Maui.exe`

> Windows might flash a security warning for unsigned apps. Click "More info" → "Run anyway".

Building from source? See [DEVELOPERS.md](docs/DEVELOPERS.md). Something broken? Check [TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).
